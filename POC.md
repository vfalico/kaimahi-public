# Whole-requirement enforcement PoC

This branch carries complete immutable Suite requirements into the experimental
Orka, Agent Sessions and kagent execution paths. Kaimahi resolves and submits
intent; the owning runtime and enforcement provider implement protection.
This is not a release extending the stable runtime support matrix.

Start with the [complete PoC guide](https://github.com/vfalico/agentsuite-guardd/tree/poc/whole-requirement-v1/docs/poc)
for exact pins, setup, build/test instructions, demonstrations and limitations.
Suite remains unchanged. Canonical module/import paths are unchanged.
